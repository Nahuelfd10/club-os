# Direccion visual - Club OS

Ultima revision: 2026-05-10.

## Criterio general

Club OS usa dos contextos visuales:

- **Panel del club**: fondo claro, sidebar oscura, lectura operativa y componentes densos.
- **Landings**: fondo oscuro, composicion limpia, mucho aire y ejemplos concretos del producto.

## Admin

- Sidebar fija oscura con navegacion principal.
- Workspace claro para tablas, formularios, cobros y caja.
- Cards blancas con borde slate suave y sombra baja.
- Tablas legibles sobre blanco, no sobre vidrio oscuro.
- Los bloques destacados pueden ser oscuros cuando cumplen una funcion de foco, por ejemplo "Hoy".

## Landings

- La landing de venta de Club OS debe ser minimalista y explicar el problema: socios, cobros, caja y seguimiento.
- El ejemplo de WhatsApp debe sentirse real y manual, no una automatizacion ficticia.
- El flujo del sistema se conserva como pieza explicativa central.
- La landing del club debe priorizar identidad, CTA de socio, equipos, proyectos y sponsors.

## Tipografia y tokens

- Sans principal: Inter.
- Display: Space Grotesk.
- Color principal de producto: azul.
- Acento: naranja.
- Radios: 12px en controles, 20-28px en cards grandes.
- Evitar que el admin parezca una landing: menos glow, mas estructura, mas contraste de lectura.
